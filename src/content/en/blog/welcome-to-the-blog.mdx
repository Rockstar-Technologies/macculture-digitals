## How posts work

Each post is one MDX file in `src/content/en/blog` (English) with a matching file of the same name in `src/content/fr/blog` (French). The block at the top of the file holds the title, date, short excerpt, tags and optional cover image.

## What you can write

You can use **bold text**, lists, links and quotes:

- News about releases and projects
- Updates from The Creative Hub
- Opportunities for independent creatives
